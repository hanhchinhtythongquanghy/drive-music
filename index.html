Hướng dẫn nhanh
  1. Lấy Client ID theo file README (Google Cloud Console, miễn phí).
  2. Mở thư mục nhạc trên Drive → copy link trên thanh địa chỉ → dán vào ô trên.
  3. Bấm "Lưu & quét", đăng nhập Google khi có cửa sổ hiện ra.
  4. Phím tắt (máy tính): Space = phát/dừng, ←/→ = tua 5s, N/P = bài sau/trước, S = trộn, R = lặp.
